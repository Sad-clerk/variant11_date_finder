# Лабораторная работа: регулярные выражения, вариант 11

**Тема:** проверка и поиск синтаксически корректных дат в формате `ДД.ММ.ГГГГ`.

## Возможности

- проверка даты, введённой пользователем;
- поиск всех корректных дат в локальном текстовом файле;
- загрузка веб-страницы по URL через `requests` и поиск дат в её видимом тексте;
- вывод найденной даты, номера строки и столбца;
- проверка существования даты в календаре, включая правила високосного года;
- объяснение конкретной причины некорректной даты (ошибка формата, диапазона дня/месяца или невозможный день месяца);
- определение, относится ли существующая дата к прошлому, сегодняшнему дню или будущему;
- автоматические unit-тесты на стандартной библиотеке `unittest`.

Поддерживаются текстовые файлы в кодировках UTF-8, UTF-8 с BOM и Windows-1251. Для веб-загрузки принимаются адреса с `http://` или `https://`. Из HTML исключается содержимое `script`, `style` и `noscript`.

## Установка и запуск

Требуется Python 3.10 или новее. Рекомендуется использовать виртуальное окружение.

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

Установка зависимости:

```bash
python -m pip install -r requirements.txt
```

Запуск приложения из корневой папки проекта:

```bash
python main.py
```

Для быстрой демонстрации можно выбрать пункт поиска в файле и указать `examples/sample_dates.txt`.

## Запуск unit-тестов

Из корневой папки проекта:

```bash
python -m unittest discover -s tests -v
```

## Принцип проверки даты

Регулярное выражение `DATE_PATTERN` выделяет строку нужного формата: день от `01` до `31`, месяц от `01` до `12`, год из четырёх цифр. После структурной проверки функция `validate_date_detailed` создаёт календарную дату и проверяет, существует ли она. Поэтому, например, `31.02.2024` и `29.02.2023` не принимаются, а `29.02.2024` принимается.

При поиске регулярное выражение сначала находит кандидатов в тексте, затем календарная проверка исключает невозможные даты. Ограничения `(?<!\d)` и `(?!\d)` не позволяют находить дату как часть более длинной последовательности цифр.

Для подробной проверки используется `validate_date_detailed`. Она возвращает результат с признаком корректности, поясняющим сообщением и дополнительным признаком будущей даты. Например, `01.01.2028` является календарно корректной датой; при запуске программы 10.11.2026 она дополнительно помечается как будущая. Сравнение производится с текущей датой компьютера, поэтому вручную менять год или дату в программе не требуется. При поиске в файле и на веб-странице будущие даты также получают пометку «относится к будущему».

## Набор тестов

Тесты проверяют корректные и некорректные даты, пояснения причин ошибок, границы дней и месяцев, високосные годы, определение прошлых, сегодняшних и будущих дат, поиск нескольких дат, координаты в тексте, чтение файлов в разных кодировках, обработку ошибок HTTP и файловой системы, а также основные ветви консольного интерфейса. Сетевые тесты используют mock и не обращаются к реальным сайтам.
